Harry Spotter 3.1 for Windows
=============================

GETTING STARTED
1. Unzip this folder somewhere you can write to, e.g. Documents
   (not Program Files). Keep all the files together.
2. Double-click HarrySpotter.exe.
   If Windows says "Windows protected your PC": click More info -> Run anyway.
   (The app isn't code-signed; this only happens the first time.)
3. Click "Open Harry Spotter". A "Connect Google Drive" window walks you
   through signing in to Google Drive for Desktop.
4. Enter the MX visit number (e.g. mx12345-1) and click Sync now.
   This pulls the latest merged data and the visit's reference PDB.
5. Choose the apo ground-state MTZ, set the chain and residue, and Run.

YOU WILL NEED
- Google Drive for Desktop, with access to the beamtime folder
  (https://www.google.com/drive/download/)
- CCP4 (for Dimple, apo screening) and WinCoot (map rendering)
- Phenix (for time-resolved Fo-Fo maps)
The Software card shows a green tick for each one it finds. If one is
installed somewhere unusual, click Locate... and choose it.

Your results are saved in the "results" folder next to HarrySpotter.exe.
